推荐 B 的理由是较小头部与较紧凑的颈身关系更便于融入外壳，同时宽扁橙嘴仍能识别为鸭子。A 更直立，C 更向前探头；推荐不代表用户已选定。

交付页提供统一视角切换和 64/128 CSS 像素对照。缩略图保留概念图灰底，用于观察缩小后的轮廓，不是最终图标或实际游戏画面。生图的开孔、尾部连接、背部结构与视图间比例仍需后续统一建模。

本阶段只修改候选资源和文档；首页、正式主题、模型资源、动画和碰撞配置尚未更改。没有启动 Blender 建模或批量制作其余款式。用户明确验收确认后，才能推进鸭子母版、三款代表模型、首页互动与20款组合模型的独立评审关。

工具：内置 `image_gen.imagegen`，共7次生图调用，其中6张为当前交付。实际竞品图标仅作为风格与组合方式参考，原始资料保留完整。

验证：六张 PNG 文件头和尺寸检查通过，最短边887像素；评审页六个图片引用、六个原图链接和三个视角控件的静态检查通过。`npm run structure:check` 的43项检查通过，319个文档链接无新增断链。浏览器自动化连接不可用，后续本地 `file:` 页面打开被浏览器协议安全策略拒绝，未尝试绕过；因此页面实际布局、视角切换及缩略图的浏览器目视检查仍待验证。当前不能将页面静态检查表述为浏览器运行验收通过。
