# 抓鸭子品牌与鸭子 UI 统一

日期：2026-10-25。UI 版本 `20261025-DUCKBRAND3`。

## 统一结果

用户确认沿用 B2 奶白鸭，并要求主界面与加载图统一为「抓鸭子」。本轮使用内置 image_gen 修改招牌、主按钮和设置三个透明资源，生成全新加载封面。招牌改为准确的三个字「抓鸭子」；主按钮文案为「开始抓鸭」。原柴犬、耳朵、爪印和骨头替换为小头长颈的奶白鸭、橙色蹼足和奶白羽毛。招牌初稿残留的手指形附件另经一次定点生图修正。

鸭子身份参考用户已确认的 B2 概念三视图与真实母模三视图。没有另造首页 3D 母模；实际首页复用鸭子任务接入的 `Mascots/DuckHome`、九骨骼与待机／招呼／点击三个动作。五个主题入口插画、主题背景和现有按钮动效继续使用。

游戏中的帮助、成绩、继续、送礼、金色目标提示均改为鸭子文案。`workspace.json` 显示名、当前根 README 与结构文档同步为「抓鸭子」。工程标识、资源追溯 ID、旧记录与竞品原始证据保留其既有标识。
