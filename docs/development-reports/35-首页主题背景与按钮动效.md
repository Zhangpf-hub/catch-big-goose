# 首页主题背景与按钮动效

日期：2026-10-25。版本：`20261025-HOME1`。Unity 2022.3.62f3。

## 已实施

首页按当前主题显示背景，对局沿用同一主题环境。使用内置 image_gen 分别生成早餐晨光、烧烤夜市、乡村小院、杂货铺、童年玩具店五张竖版背景；修除烧烤原稿右上角的非场景符号。生成背景不包含按钮、文字、角色或桌台，中央留空用于实时柴犬、展台和关卡物堆。

首页保留五主题、设置和开始共七个入口，移除成绩、玩法按钮。标题使用明黄色招牌和白边贴纸字；主题入口加入珊瑚、薄荷、紫色底板。开始按钮加宽，采用蓝底白字和爪印。

底板继续使用独立九宫 Sprite；星花、爪印由 UI 网格按照最终按钮尺寸绘制，文字与插画保持独立。主按钮每 4.8 秒进行一次短扫光，有轻微呼吸；当前主题轻晃；所有按钮有按压和松开回弹。动画使用非缩放时间，不创建逐帧协程或材质实例；装饰不拦截触摸。真实 3D 柴犬的呼吸、轻晃与点击反馈保留。

## 美术源与运行资源

- [生图原稿与完整提示词](../../source-assets/ui/home-theme-v1/)：五个 `*-master.png` 与 `prompts.json`，使用内置生图工具。旧 R4 和首版导入图保留在该目录的归档子目录。
- [运行背景](../../projects/catch-big-goose-unity/Assets/Resources/Textures/mobile-ui/themes/)：768×1152 的 JPEG，以 `*-v1.bytes` 保存；五张编码数据合计约 1.15 MiB。
- [编码脚本](../../tools/art/prepare-home-theme-art.cjs)只进行尺寸和编码转换，不重画生图内容。
- [按钮 SVG 与九宫契约](../../source-assets/models/candidates/ui-candy-v2/)通过原有矢量管线增加三种配色；角框保持原切片规格。

首轮把 JPEG 当 Unity Sprite 导入，五张背景在构建数据中各约 2.7 MiB，最终微信包 37,671,537 字节，被原有 30 MiB 守卫拒绝发布。最终改为保存 JPEG 编码字节，只解码当前主题；创建完整 mipmap、Trilinear 和 Clamp，上传后释放 CPU 像素副本，切换主题销毁上一张动态纹理和 Sprite。资源预加载与编辑器审计同步识别 JPEG 字节并检查存在性，缺失仍报错。
