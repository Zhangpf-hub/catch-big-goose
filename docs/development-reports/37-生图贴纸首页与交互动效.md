# 生图贴纸首页与交互动效

日期：2026-10-25。首页资源版本 `20261025-STICKER2`；保留当前主工程的 `HOME2-SHAKE3` 桌台、光照与玩法改动。

## 视觉重做

用户否定 HOME1 的通用圆角框表现后，本轮使用内置 image_gen 分别制作八张透明资源：游戏招牌、柴犬蓝色开始按钮、早餐／烧烤／乡村／杂货／玩具五主题入口、齿轮设置。每个主题入口由主题道具插画和卷边横幅组成，取代“通用框内放一个小图标”。完整中文招牌由生图制作，按钮与主题文字在 Unity 中单独排版。

[原稿、完整提示词和资源契约](../../source-assets/ui/home-stickers-v2/)保留生成结果；[编码脚本](../../tools/art/prepare-home-stickers.cjs)只缩放和无损 PNG 编码，保留真实透明通道。运行素材总计 1,016,880 字节，存为 PNG 字节；运行时带 mipmap 解码并释放 CPU 像素副本。原来的五主题生图背景继续使用。

插画以固定设计比例绘制并开启 `preserveAspect`，没有把整张插画九宫拉长。按钮根节点保留固定九宫命中区，插画作为独立视觉子节点：长宽比和点击区域不受弹跳或按压影响。标题、主按钮和主题入口均不再叠加 HOME1 的重复爪印、花朵底纹。

技能检索使用 skill-installer 查询官方 curated 列表。本轮未发现专门解决 Unity 卡通游戏按钮美术的技能；继续应用已有 imagegen 技能，通过逐资产美术规格、透明度检查、真实场景审图和迭代提高完成度，未安装与工程无关的网页或 Figma 技能。

## 动画与交互

- 首页元素错峰入场，带位移、旋转和弹性回落。
- 主按钮呼吸、间歇弹跳；主题入口独立摆动，当前主题幅度更明显。
- 按下压缩约 9.5%，松开回弹并发射星芒；进入目标界面前保留 0.14 秒反馈窗口，并防止重复触发。
- 主按钮周围间歇闪星，使用容量固定的 UI 粒子网格，不创建逐帧 GameObject 或材质。
- 所有动画只改视觉子节点；根命中区域保持稳定。实际 UI Raycast 检查透明根命中区可以点击，插画与星芒不会拦截触摸。
