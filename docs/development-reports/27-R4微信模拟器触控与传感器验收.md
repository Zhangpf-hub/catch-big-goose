## 传感器阻断与处理步骤

【观察】每次进入或恢复关卡，微信拒绝 `wx.startAccelerometer`，当前错误是 `please go to mp to announce your privacy usage`。

【确认·官方文档】微信小游戏[隐私保护指引](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/privacy.html)将“加速传感器”对应到 `wx.startAccelerometer`；错误表说明该提示对应后台尚未声明信息类型，或声明了不使用信息。它不同于用户拒绝授权，也不能仅归因为模拟器不支持。

需要由账号管理员在 **AppID `wx60b50db2472c4782`** 的微信公众平台完成核对：

1. 打开“设置 → 基本设置 → 用户隐私保护指引”。部分后台入口位于“设置 → 服务内容声明 → 用户隐私保护指引”。
2. 按游戏实际行为声明“加速传感器”，对应接口 `wx.startAccelerometer`。
3. 用途可按当前代码填写：“用于检测手机摇晃，触发游戏物品的本地物理重排。原始加速度数据仅在设备内处理，不保存或上传。”如后续接入数据上报，应同步修订。
4. 保存并按平台要求完成审核或生效流程，然后重新进入当前预览包验收。

本轮没有修改账号隐私设置，也没有代替用户操作权限弹窗。Computer Use 的 [SKILL.md](C:/Users/123/.codex/plugins/cache/openai-bundled/computer-use/26.1021.31345/skills/computer-use/SKILL.md)要求遵循其 guidance 中“Do not change … any in-app security or privacy settings.”，因此这一配置操作交由用户完成。

声明生效后需重新验证：启动 API 成功、实际加速度回调进入控制器、真实摇晃触发重排、冷却生效、暂停与退出停止监听、恢复后重新监听、道具计数不变。若后续返回“未实现隐私弹窗”，再根据该账号已经选择的授权方案补齐；本轮不擅自开启官方文档明确为开启后不可关闭的原生弹窗组件。
