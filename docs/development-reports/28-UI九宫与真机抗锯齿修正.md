# UI 九宫与真机抗锯齿修正

日期：2026-10-25，版本 UI2。关卡配置与 R4 物理流程保持不变。

旧界面已经启用 `Image.Type.Sliced`，问题是成品胶囊位图采用统一边界后被套到方形入口、长按钮及高弹窗，切片穿过曲面与高光。移动档又关闭 MSAA，iOS 固定 1.5 倍像素比，插画缩小时没有 mipmap。位图尺寸高本身不能解释这些现象。

本轮用原生 SVG 制作符合九宫边界的背景：按钮 256×192、四边 64px，面板同尺寸、四边 48px，PPU multiplier 2。角、白边、棕边与底座固定；文字和插画独立。背景及工具插画使用无损 RGBA32、mipmap 和三线性采样，插画导入上限按实际显示大小限制为 256。仅首页五个缩小图标额外启用 mipmap，保留收藏资源预算。新素材源文件位于 `source-assets/models/candidates/ui-candy-v2/`，旧资源及 GUID 归档到 `source-assets/ui/UiNineSliceBaseline-20261025/`。

移动档和 WebGL 默认画质开启 2× MSAA，WX 初始化及 iOS 导出请求 2 倍像素比。保留设置中的 1.5 倍对照入口。像素比变化会增加约 78% 渲染像素，手机持续帧率需要真机另测，不能用桌面 GPU 的结果保证。

完整原因、34 项编辑测试、15 组九宫网格验证、多尺寸实际渲染、Windows 正式包和最新微信预览码见[本轮交付](../../work/ui-quality-20261025/README.md)。[同一渲染器的旧／新九宫对比](../../work/ui-quality-20261025/final-player/nine-slice-comparison.png)、[首页前后](../../work/ui-quality-20261025/home-before-after.jpg)、[实装画面](../../work/ui-quality-20261025/ui2-actual-game.jpg)均为实际 Unity 渲染。

官方说明：[WebGL 画布与像素比](https://docs.unity3d.com/2022.3/Documentation/Manual/webgl-canvas-size.html)、[WebGL 抗锯齿支持](https://docs.unity3d.com/2022.3/Documentation/Manual/webgl-graphics.html)。
