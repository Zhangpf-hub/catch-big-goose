# 市集风 UI 与画风优化

日期：2026-10-24。本轮以用户提供的《抓大鹅》首页截图为直接视觉参考，继续调整 Unity 主工程。参考原图归档在 `reference-projects/competitor-goose/2026-10-24-ui/user-home-reference.png`，只用于比较，没有作为游戏运行资源。

## 参考画面的特征

截图使用灰米色水泥地面与旧绿色推车作为背景，中央是白色圆桌和高饱和度的小物件、大鹅陈列。界面入口靠两侧排列，底部蓝色主按钮最醒目。按钮有白色外边、棕色轮廓与底部投影，文字粗、对比强，金色横幅用于主题内容。参考属于生活场景背景与卡通 UI 的组合。

本项目上一版浅蓝底、规则卡片网格和单只插画鹅缺少这种场景感。本轮采用上述视觉层级，保留五主题、三档难度、本地成绩和玩法说明的真实功能，不填入未实现的活动、奖励或公共排名。

## 已落地的调整

- 首页：市集地面、白色圆桌与多只大鹅陈列；两侧的五个场景入口可选择主题，当前项显示红色标记。
- 底部：金色主题横幅、难度选择、蓝色“抓大鹅”主按钮、绿色每日次数标记；成绩和玩法入口打开实际弹窗。
- 控件：白边、暖棕色轮廓、投影与顶部高光；主标题与重要文案用粗描边文字。每日次数标记不拦截主按钮点击。
- 对局：统一低干扰市集地面；七格槽、道具区和弹窗沿用同一按钮风格；固定道具标签字号由 58 调到 76 后重新烘焙。
- 3D：桌面光照减少偏黄；移动端无阴影材质提高阴影面填充光，保留朝向明暗，改善灰暗物件的辨识。
- 适配：沿用安全区和独立相机视口；陈列图保持比例缩放。新背景与陈列图导入上限为 1024，不新增首页实时 3D 相机或实时阴影。

圆桌为原创静态陈列图，实际对局仍使用项目自己的 3D 模型。模型几何和贴图没有在本轮整体重制。

## 验证入口

`powershell -File tools/unity/run-ui-acceptance.ps1 -MobileProfile -OutputDirectory work/ui-market-20261024/final-mobile`

已有最新 QA 包时加 `-SkipBuild`。`-MobileProfile` 在实际 Windows 播放器启用生产移动端材质和性能配置，不等于手机真机验收。

覆盖 360×640、390×844、430×932、768×1024、1024×768、390×844 模拟安全区，轮流选择五个主题。检查边界、文字高度、触控大小、主题卡与主按钮回调、玩法/成绩弹窗、实际物件射线拾取和暂停按钮。原有验证资料保留在 `work/ui-mobile-20261024/`；本轮资料另存 `work/ui-market-20261024/`。

工程中的 HUD 使用相机画布、弹窗使用覆盖画布，边界检查和点击采样分别按实际画布相机转换到屏幕坐标。复测曾发现旧检查直接使用世界坐标，造成 180 项误报；原始报告保留在 `bounds-diagnostic/`，最终结果以修正后的验收报告为准。
