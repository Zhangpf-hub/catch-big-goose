# 正常模式分层与 SHAKE5 表层重排

日期：2026-10-26。当前目标设备为 iPhone 15 Pro。用户已反馈“不卡了”，同时指出旧摇动仍像抖一下；这一主观反馈不代替当前新包的持续帧率或真实传感器验收。

## 实施与审批

本轮先完成[实施计划和独立审批](../development-plans/mobile-surface-performance-20261026.md)，再分工实施。研究 Agent 负责原始竞品证据与表层换位动画；深度 Agent 负责激活、支撑与渲染；独立审批 Agent 负责计划审查、外部几何夹具、实际运行验收及最终复核；主 Agent 负责手机摇动、集成和交付。

竞品依据见[正常模式分层、手机摇动和局部重排研究](../../competitor-analysis/normal-mode-surface-activation-20261026.md)。原始参考文件与冻结证据未修改。手机加速度、ToolShake 与 ToolMessUp 三条链分别记录，未混写成一个“全堆打乱”。

## 当前行为

隐藏库存保留静止碰撞支撑，kinematic 且关闭重力。可见侧面支撑继续静态渲染。只有处于当前活动高度带、经过实际凸包曝光检查的表层进入动态物理和摇动候选；休眠不会失去表层资格。渲染隐藏、动态资格和库存保持独立。

取消了剩余70件时全部渲染、全部动态的捷径。拾取只通知实际支撑邻域，前沿及时跟随真实剩余最高点下降；自然坠落也更新前沿，避免剩3件时还等待原12米高度缓慢下降。每次分类最多256次查询，开局先分帧完成分类，再展示真实可见物品。摇动期间下层不因补足数量而解冻，重排动画期间暂停假曝光晋升及容器收拢。

重排道具固定当前表层集合，做短时公转及集合内位置置换。异尺寸落点按实际凸包验证，规划和最终复验分帧执行；失败或取消退还道具，跨局恢复受当前容器和实例身份保护。少于两个可交换目标时返回无可用重排且不消费。

SHAKE5保留原有双峰检测门槛，接受一次真实手势后提供明确的最低反馈强度。首步提前水平扰动，前0.14秒按有限预算重试被接触抵消的抬升，随后自然落下。目标上行速度2.8、累计正上行增量上限5.4、水平有符号增量上限2.4、注入速度限值4.5均为项目参数；已有重力或碰撞速度不会被当作无预算急刹。未改变深层物理、摩擦或模型材质来通过效果检查。

## 已取得与待完成的证据

64项编辑测试通过，包括12件独立暴露几何、被覆盖支撑、休眠资格及快落速度预算边界。普通1.6g合成输入的原生画面已验证6件受力、6件移动/翻转，3件保留达到门槛的水平净位移。这里的位移是游戏场景单位，不是手机的移动距离。

其它GPU/CPU风险见[性能审计](mobile-performance-audit-20261026.md)：正常模式会重新开启实时阴影，实际批次与手机GPU成本仍需测量。没有通过关闭阴影、透明附件、DPR2或2×MSAA获得本轮结果。并行SIZE1工作调整了默认模型大小，旧基线与新包的提交数不能简单归因于单项性能修改。

当前实现和本地验收不代表 iPhone 15 Pro 新包的持续帧率、温升或真实传感器摇动已经通过。待完整本地矩阵和新预览包就绪后，以同一BuildId采集真机数据。
