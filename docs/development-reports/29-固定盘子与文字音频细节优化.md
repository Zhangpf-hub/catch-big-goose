# 固定盘子与文字音频细节优化

日期：2026-10-25。版本：`20261025-R4-UI3`，基于当前 Unity 2022.3.62f3 源工程。

## 盘子与可放置空间

原先消除进度同时驱动物理边界、盘子横向缩放和盘沿纵向拉高。现在只收紧物件的活动半径：五个主题的盘子模型、位置、盘沿及镜头角度保持固定。收拢速度、物件尺寸、库存和关卡配额沿用原配置。

可见盘沿的碰撞与固定盘子对齐，避免内移到没有画出来的位置挡住点选；内部收拢边界继续承接物理碰撞，并从点选射线中排除。回归检查同时验证初始及后期模型包围盒、缩放、盘沿位置、镜头角度，以及防穿底、防越界、摇动和实际可点选性。

首轮 300 件乡村关发现一件薄扇子穿过移动边界后停在外圈。补充每个物理步的中心越界保护：只纠正越界的水平位置并去掉向外速度，保留高度、角速度和切向速度，防止它在固定大盘子的外部停留。保护持续覆盖收拢结束后的摇动。原真机摇动诊断面板默认关闭，开发包可带 `-gooseShakeDiagnostics` 显示。

## 文字

- 普通字与真正的粗体分别使用 Noto Sans CJK 派生子集，标题、按钮、计时使用粗体字形，取消运行时模拟加粗与厚重描边。
- 动态字以设计尺寸的两倍生成，再以半尺寸显示，保持版面尺寸，提高小屏字形精度。新增一层文字布局节点，性能与摇动诊断面板改挂到独立状态栏根节点。
- 统一深灰棕正文与奶油色底板；主题名、弹窗标题改用深色，首页提示增加浅底，当前主题增加小底牌。蓝色主按钮保留白字和轻投影。
- 道具标签重新使用粗体烘焙为 512×224 无损透明贴图，保留 mipmap 与三线性过滤；其余插画继续使用已有预算。

粗体来自 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf)。完整源字体位于项目 `SourceAssets/Fonts`，运行资源只含约 264 KiB 的两份子集。保留 OFL 及版权表，派生家族更名为 Goose UI CJK / Goose UI CJK Bold。字形清单和 SHA-256 记录于 `work/wechat-integration/font-subset.json`。新增中文文案仍须运行 `tools/unity/subset_ui_font.py`。

## 音乐与音效

新背景音乐为原创程序合成，124 BPM、16 小节、约 31 秒循环，使用木质弹拨旋律、反拍和弦、跳跃低音及柔和轻打击，替代原来 96 BPM 的八音盒与长音铺底。尾音按循环叠加，播放和暂停加入约 0.2 秒的音量过渡。

摇一摇使用独立的 0.36 秒低频木质碰撞与沙沙声，不再复用原打乱音效。打乱另换为 0.5 秒同类音色。播放增益分别为 0.48 / 0.62；音乐主音量为 0.32。沿用已有音乐音效开关，不改玩家已保存的设置。

生成工具：`tools/unity/prepare_polish_audio.py`；合成固定随机种子。源音频峰值不超过 0.72，摇动／打乱的 4 kHz 以上能量占比低于 0.5% 检查阈值。可复核 WAV 和频谱审计位于 `work/detail-polish-20261025/audio`。原背景音乐与打乱音效备份在同批次 `old-assets`，参考工程和冻结证据未改动。
