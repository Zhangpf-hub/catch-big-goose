删除前以正式主题、鸭子评审、参考关卡、金鸭与场景装饰的动态加载路径建立保留集合，再检查 YAML GUID、FBX 导入映射和材质 JSON；删除目标的外部序列化引用为 0。删除清单和 SHA-256 见 `work/resource-cleanup-20261026/deleted-resources.json`。可恢复副本位于同目录 ZIP，处于活动工程和发布目录之外；原始参考数据与冻结证据未更改。

材质资源清单从 116 条收敛为当前 108 条，尺寸配置从 147 条收敛为当前有效的 101 条；所有保留条目的参数不变。原始 116 条权重来源记录继续保留用于来源校验。资源导入工具跳过明确退役的模型与无需求贴图；构建检查会拒绝重新出现的退役资源。旧 `GooseWeChatLegacyResources` 已删除，构建不再恢复旧文件。
