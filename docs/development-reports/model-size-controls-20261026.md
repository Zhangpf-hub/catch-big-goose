# 道具占屏大小修复与设置滑条

日期：2026-10-26。构建标识：`20261026-SIZE1-SURFACE1-SHAKE4`。

## 问题与改动

原先 R2 报告的 0.70 是当时工程的公共基础尺度，不是物件占屏百分比。当前主题模型、相对尺寸表、俯视角和顶部货车留区均已变化，仅保留 0.70 不能保证与历史截图相同的占屏效果。短屏相机为保证完整容器仍有半高 2.10 的兜底，实际横向世界范围也可能大于长屏的 3.90。这次针对用户反馈修正实际物件尺寸，不将数值相同当作比例已经对齐。

- 默认模型线性尺寸为此前的 **130%**。公共底数 0.70 对应的新默认基础长度为 0.91；各类型相对尺寸及变体仍参与计算。
- 首页“设置 → 模型大小”，局内“暂停 → 模型大小”，均可进入调节面板。
- 拖动范围 **70%～160%**，步进 **1%**，显示当前百分比；提供 `−1%`、`+1%`、恢复默认。
- 局内暂停后即时预览，底部面板使上方物堆保持可见；确认后继续本局。不会重置库存、积分、时间或扣除新的次数。
- 尺寸调整同时作用于模型与碰撞体；确认时按真实凸包找容器边界和接触位置。避免仅用外接框把蒸笼、油条等物件挤成中央高柱。
- 新生成物堆使用相同的凸包摆放方法，修正大尺寸 300 件档触发旧 80 次外接框寻位上限的问题。
- 移出、七格栏中的物件保留适配后的回堆尺度，七格显示继续适配栏位。
- 本地保存使用版本化键；首次加载使用修正后的默认值。后台准备缓存包含当前尺寸，旧尺寸布局须通过逐件尺度检查才能使用。
- 正交相机高度增加到 40，准备物堆高度上限 34，围挡覆盖高度 64。正交相机升高不改变物件占屏比例，目的是覆盖大尺寸完整库存。
- 游戏阴影距离随相机抬高量同步增加，保留原有的地面阴影覆盖；首页继续使用自身灯光与阴影配置。

这里的 130% 是项目相对尺寸，不是单件占屏宽，也不是声称恢复了竞品最终运行参数。竞品原始数据及冻结证据保持原样。
