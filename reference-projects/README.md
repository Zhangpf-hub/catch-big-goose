# 参考项目

本目录独立保存参考工程和竞品源资料，当前开发入口位于 [Unity 工程](../projects/catch-big-goose-unity/README.md)。

| 子目录 | 内容 |
| --- | --- |
| `catch-big-goose-cocos/` | 迁移前 Cocos Creator 工程，保留原始资源、配置、构建与历史说明 |
| `catch-big-goose-web/` | 早期网页原型；`src/` 为原 web 源码，另保留 HTML、图标和 TypeScript 配置，不作为当前可运行版本 |
| `competitor-goose/` | 按日期归档的竞品模型、贴图、参数及提取结果，是参考资源集，不宣称为完整竞品 Unity 源工程 |

竞品研究结论和证据位于 [competitor-analysis](../competitor-analysis/README.md)。本项目实施和验收报告位于 [docs](../docs/README.md)。
