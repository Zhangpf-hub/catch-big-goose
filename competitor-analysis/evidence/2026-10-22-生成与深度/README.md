# 生成与深度证据快照

研究样本日期为 2026-10-22；归档时间见 [验证汇总](验证汇总.json)。方法证据取自 AppID `wxb98ac240fd74b0e3` 本地版本 `401`。本目录不包含可运行的完整竞品。

- `方法体/`：34 个签名匹配方法、6 个排除入口、WAT 正文和静态校验后的分析模块。模块的外部依赖为 imports，未作为完整游戏执行。额外三份包装／泛型片段不计入 34 个方法。
- `来源/`：首轮分包清单、元数据和两个 WASM 的哈希。`recovery.json` 保留首轮 18 方法的历史记录，当前 34 方法以 `方法体/method-map.json` 为准。
- `验证/`：五个原方法的隔离执行模块、606 组数值和 2,048 次抽取轨迹，实际生产 C# 测试结果、Unity 编辑测试 XML、开发包 71 项检查和玩家日志。
- `Unity源码快照/`：实际被本次开发包使用的七个运行文件，归档时与构建记录哈希逐项核对。
- `复现源码/`：本次配置、测试、构建与复现工具。机器路径和大型中间文件依赖见第 06 章。
- `文件校验.json`：相对路径、文件大小和 SHA-256，不包含自身。

`source-hashes.tsv` 是构建时生成的原记录，保留原格式。隐藏和托住数量是该次实际物理时序的快照，重复运行可能不同。数值探针使用宿主 RNG 和 IL2CPP 访问适配器，不能代表完整竞品执行或实际关卡配置验证。

五个原方法的探针不具备 wx、网络、文件或完整游戏启动导入。直接反复执行 RollIndex 的越界状态只说明该测试调用域的现象，不能据此判断原游戏完整生命周期有缺陷。详见 [生成算法](../../03-生成算法.md)。
