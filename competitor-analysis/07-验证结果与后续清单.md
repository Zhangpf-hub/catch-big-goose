# 07 验证结果与后续清单

## 2026-10-24 核心单局增量

最新[验证汇总](evidence/2026-10-24-核心单局与运行配置/验证汇总.json)：原方法 AB 桶配置 2,500 项与 28 个额外边界；生产 C# 104,031 项（新增百分桶等政策，旧数学／随机／配额夹具继续保留）；Unity 编辑测试 14 项、实际开发包 132 项。后者含五主题 300 件深堆、15／60 件档、按层实物数量、三件组、暂存取回、单次工具上限、清盘和支撑／唤醒。自动选择绕过手动遮挡，不能据此声称人类一定可解。

复跑发现并修正两个真实边界：旋转后碰撞中心与原点不一致导致打乱找不到净空；暂存件保留原隐藏状态导致无法手动取回。第二项触发了旧测试无限重试，产生 OutOfMemory；已限定重试次数，并强制把暂存件设置为隐藏再验证 UI 取回。失败报告／日志与修复后报告分开保存，没有只保留成功输出。

两模块分析模块静态验证通过：588 入口／440 函数体与 128 入口／126 函数体，没有地址重叠。常量间接调用点 1,018 个只代表语法边。5 件新烘焙蒙皮参考 GLB 回读与 Khronos 检查通过（0 错误／警告），四视图实际查看；不是可播放原动画或正式碰撞资源。

Windows 可玩包重建成功。另完成离屏渲染检查 11 项，查看首页及三个核心档的实际画面；标准档含三个暂存图标。最初隐藏窗口截图全黑，改为显式绘制真实相机／HUD 后才通过视觉检查。[画面审阅记录](evidence/2026-10-24-核心单局与运行配置/画面/visual-review.json) 与规则验收分开，不等同于真人点击或手机性能。

默认核心档与旧回归档分开验收；下文 2026-10-23 的数字为当时结果，保留作为历史阶段，不能替代最新源码验证。

受控物理场景额外验证：有上层覆盖的底层件被隐藏和托住，支撑碰撞保留；手动不能选取该隐藏件；取走上层件后立即恢复底层动态；无遮挡的深层件重新显示。它验证了具体恢复路径，不能推导复杂堆叠中所有人工操作都已验收。

## 上一轮记录的限制与后续研究

**2026-10-22 时的证据缺口：** 实际关卡权重、序列化后的深度参数、全部模式实现、完整 Roll/Check/RemoveItem 生命周期、固定种子、必定可解机制、实时槽位难度调整。其中本地基础权重、场景参数和部分模式链已在 2026-10-23 补充；当前缺口以第 11 章为准。

**自有项目仍需验收的部分：** 人工鼠标／触摸的遮挡和点选手感、实际渲染下的隐藏切换、打乱连续使用的观感、长时间与移动端性能，以及 WebGL／微信 SDK 真机发布。本轮开发包采用 `-nographics`，真实物理通过不等于画面验收或性能结论。五射线保护与全体唤醒均是保守初版；如后续性能不足，可在测量后改为接触邻域唤醒和更精确可见性判断。

**美术待办：** 现有正式高面数物件尚未批量重制，Shader 未对齐，原创玉米仍待实际场景效果确认。本轮保留正式资源，提供参考和预算证据，未把模型候选当成已经上线的替换。

权重与深度功能本轮已接入并开启；以上待办是明确的剩余边界，不影响已经记录的数值、库存及实际 Unity 状态检查结果。
