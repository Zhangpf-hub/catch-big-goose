# 首页视觉层次与主题背景对照

日期：2026-10-25。来源为用户提供的竞品首页截图，以及此前记录的首页动画观察；静态截图不能用于测量动画频率、幅度或帧率。

竞品首页用中央白色展台承载物品，入口贴在两侧，底部蓝色主按钮占据最高操作优先级。按钮以白色厚外边、暖棕轮廓、饱和色面、插画与贴纸文字组织层次；辅助入口还使用红点、旗标和图案。地面背景的对比度低于物品和按钮。

| 对照维度 | 竞品参考 | 本轮设计选择 |
| --- | --- | --- |
| 首页构图 | 中央真实物堆，两侧活动入口 | 中央真实柴犬与主题物品展台，两侧五个主题 |
| 主操作 | 底部高饱和蓝色大按钮 | 蓝色九宫按钮，独立爪印、扫光和白字 |
| 主题辨识 | 活动插画与主题招牌 | 早餐暖黄、烧烤珊瑚、乡村薄荷、玩具紫色，配对应环境 |
| 动态表现 | 用户观察到的角色、按钮动画 | 小幅呼吸、当前主题轻晃、点击压缩回弹；实际录像另见开发报告 |
| 背景气氛 | 街市地面与摊位 | 五张生图环境，中央空地承接实时 3D，边缘说明主题 |
| 信息密度 | 活动、排名、收集等多入口 | 首页保留主题、开始和设置；按用户要求取消成绩、玩法入口 |

当前仍有差距：竞品的活动插画形状更自由、前后遮叠更丰富，中央展台物品也更密集。本轮首先统一背景、按钮颜色与反馈节奏；对照不意味着这些细节已经逐项相同。

并排图包含用户竞品截图、UI5 实际旧画面、HOME1 实际 Unity 画面；旧画面为早餐主题、新画面为烧烤主题，适合比较布局与视觉层次，不是同主题材质的严格 A/B。原始竞品截图保留原比例。
