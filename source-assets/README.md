# 美术源资源

- `models/`：模型候选、加工规格和相关原件，原目录为 `assets-3d/`。
- `ui/`：工作区级 UI 原件和九宫备份，原目录为根 `SourceAssets/`。
- `videos/`：两支原始视频及原下载记录，原目录为 `video/`。

Unity 实际加载的资源在 `projects/catch-big-goose-unity/Assets/`，该工程自己的加工备份位于其 `SourceAssets/`。资源生成工具位于 `tools/art/` 与 `tools/unity/`。

竞品提取原件集中在 `reference-projects/competitor-goose/`；研究证据集中在 `competitor-analysis/`。本次目录整理不改变资源许可与来源说明。
